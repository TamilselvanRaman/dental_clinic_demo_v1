# SmileCare - Dental & Implant Studio (Demo)

A premium, modern, and fully responsive landing page designed for **SmileCare - Dental & Implant Studio**. 

This demo showcases a sleek user interface with curated color palettes, elegant typography, smooth micro-animations, and interactive components.

## ✨ Features

- **Responsive Layout:** Optimized for all devices (Mobile, Tablet, and Desktop).
- **Interactive Doctor Cards:** Hover animations to highlight team expertise and credentials.
- **Before/After Slider:** An interactive, draggable image comparison tool to visualize dental treatment results.
- **Testimonials Carousel:** A smooth testimonials slider showcasing patient reviews and Google ratings.
- **Appointment Booking Modal:** A user-friendly modal that allows patients to request appointments.
- **Scroll Reveal Animations:** Micro-animations that activate as the user scrolls, creating a premium feel.

## 🛠️ Built With

- **HTML5 & Semantic Elements** - Structured for SEO and accessibility.
- **Tailwind CSS (via CDN)** - Modern design tokens and utility classes.
- **Vanilla JavaScript** - Clean, framework-free interactive logic.

## 🚀 How to Run Locally

Since this is a static client-side project, you can run it instantly:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TamilselvanRaman/denta_clinics_demo.git
   ```
2. **Open the project:**
   Simply double-click `index.html` to open the landing page directly in your web browser.
